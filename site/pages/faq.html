Frequently asked questions

How do I open a .pub file now Publisher is retired?

Install OpenPub, then open the .pub file from File › Open, by dragging it onto the window, or by right-clicking it in File Explorer and choosing Open with › OpenPub. OpenPub reads files from Publisher 2002 to 2021 and Microsoft 365. After opening, a short report lists anything that was changed on the way in.

Is OpenPub free?

Yes. OpenPub is free to download and use, including at work, and its source code is open under the MIT licence. There are no accounts, subscriptions or advertising.

Does OpenPub save .pub files?

No. Microsoft has not published the .pub format, so OpenPub reads it but does not write it. Your work is saved as an OpenPub project (.opub), and you can export PDF, PNG, JPEG and SVG. The original .pub file is never changed.

Which Publisher files can it open?

Files from Publisher 2002, 2003, 2007, 2010, 2013, 2016, 2019, 2021 and Microsoft 365. Files from Publisher 98 and Publisher 2000 use an older format and cannot be opened.

Are my files uploaded anywhere?

No. OpenPub opens, edits and exports everything on your computer and works without an internet connection. The privacy page describes the one optional network request: checking for a new version.

Should I use the installer or the portable zip?

The installer adds OpenPub to the Start menu, opens .opub projects when you double-click them and offers OpenPub for .pub files, without changing your default program for them. You can install it just for yourself (no administrator rights needed) or for everyone on the computer. The portable zip needs no installation: unzip it anywhere and run OpenPub.exe.

Why does Windows warn me when I run the installer?

OpenPub's releases are not yet code-signed, so Windows SmartScreen does not recognise the publisher. Choose More info, then Run anyway. The code signing policy explains how releases are built from the public source code and the plan to sign them.

Does OpenPub update itself?

From version 1.3.0, OpenPub can check for new versions. The first time it starts, it asks whether to check automatically, and it makes no update check until you answer yes. You can change your answer later, and Check for updates works at any time. When a new version is found, OpenPub asks before downloading it. The portable zip only tells you a new version is available and links to the download page. The Microsoft Store version is updated by the Store.

Can my IT department turn off update checks?

Yes. From version 1.3.0, set this registry value, for example through Group Policy preferences:

HKEY_LOCAL_MACHINE\SOFTWARE\Policies\OpenPub, value DisableUpdateCheck, type REG_DWORD, data 1.

The same value under HKEY_CURRENT_USER\SOFTWARE\Policies\OpenPub applies to one user (for a per-user Group Policy). OpenPub then makes no update checks at all, does not ask about them, and its Check for updates command says updates are managed by your organisation. For unattended installs, the installer accepts /S /allusers (everyone on the computer, run as administrator) or /S /currentuser.

The text looks different from Publisher. Why?

OpenPub uses the fonts installed on your computer. If a publication uses a font you don't have, another font is used in its place and the import report and the design checker list it. Installing the font fixes it.

Can I send a CMYK PDF to a print shop?

Yes. Vector CMYK PDF needs Ghostscript, which is free but not included with OpenPub because of its licence. Install it from ghostscript.com and OpenPub finds it automatically; you can also choose the colour profile your printer asks for.

Is there a Mac or Linux version?

Not at the moment. OpenPub is released for Windows 10 and 11 (64-bit).

How do I uninstall OpenPub?

Open Windows Settings › Apps, find OpenPub and choose Uninstall. It asks whether to keep your settings and personal dictionary. For the portable zip, delete its folder.

Where do I report a problem?

Open an issue on GitHub. For a security problem, please report it privately through the repository's Security tab instead.
