Code signing policy

This page says how OpenPub's Windows releases are built, who is responsible for them, and how they are signed.

Signing status

OpenPub releases are not yet code-signed. OpenPub is applying to SignPath Foundation for free code signing for open-source projects. Once the project is accepted, signed releases will carry this statement:

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

The publisher shown by Windows for a signed release will be "SignPath Foundation". Until then, Windows SmartScreen may warn the first time you run the installer; see the FAQ.

What is signed

  • OpenPub.exe, the program itself
  • The installer, OpenPub-<version>-win64-setup.exe

The uninstaller that the installer puts beside the program, Uninstall OpenPub.exe, is not signed: it is made inside the installer while the installer is built, where signing cannot reach it.

Only files built from OpenPub's own source code are signed. Electron's files that ship with the app are included unchanged from the Electron project.

How releases are built

  • All source code, build scripts and build settings are public, in the sarinityx/OpenPub repository under the MIT licence.
  • Release files are built by GitHub Actions on GitHub-hosted runners, from the repository, by the release workflow. They are not built on a personal computer.
  • Every change reaches the main branch through a pull request that must pass the automated tests. Direct pushes and history rewrites are blocked.
  • Signing is part of the release workflow: OpenPub.exe is signed first, the installer and the portable zip are built from the signed program, then the installer is signed. The signing configurations are in the repository's .signpath folder.
  • Every signing request is approved by hand before anything is signed.
  • Published releases cannot be changed afterwards: release files and tags are immutable on GitHub. A mistake is fixed with a new version.

Team roles

  • Committers and reviewers: sarinityx (project owner)
  • Approvers: sarinityx (project owner)

Changes proposed by anyone else are reviewed by the owner before they are merged. Everyone on the team uses multi-factor authentication for GitHub and SignPath.

Privacy

OpenPub sends no information to other networked systems unless the user or the person managing it asks it to: the only such request is the optional update check. Details are on the privacy page.

Checking a signature

From the first signed release, OpenPub's update check installs an update only if Windows accepts its signature and it is signed with the same certificate as the version you have.

For a signed release, right-click the installer or OpenPub.exe in File Explorer, choose Properties, then the Digital Signatures tab. The signer should be SignPath Foundation.
