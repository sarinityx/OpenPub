Privacy

OpenPub opens, edits, prints and exports your files on your computer. It has no accounts, advertising, analytics or crash reporting, and it never sends your files or anything about them anywhere.

This program will not transfer any information to other networked systems unless you or the person who installs or manages it asks it to. The one case is the update check described below.

Update checks (from version 1.3.0)

When: only if you agree. The first time OpenPub starts, it asks "Check for updates automatically?". Until you answer yes, it makes no update check. If you agree, it checks once shortly after starting, and at most once a day. Check for updates on the menu checks once, when you choose it.

What is sent: requests to GitHub for the details of OpenPub's latest release, including a small file named latest.yml with the version number and file size. Like any web request, they reveal your IP address and the program making the request to GitHub. Nothing about you, your files or your use of OpenPub is included.

Downloads: if a new version is available, OpenPub shows a notice and downloads it only when you choose Download. The download also comes from GitHub. The portable zip never downloads updates; its notice links to the download page instead.

Who receives it: GitHub, which hosts OpenPub's releases. GitHub's handling of requests is described in the GitHub General Privacy Statement.

How to turn it off: answer no to the first-start question, or change the setting later. An organisation can turn update checks off with the registry value DisableUpdateCheck = 1 (REG_DWORD) under HKEY_LOCAL_MACHINE\SOFTWARE\Policies\OpenPub (everyone on the computer) or HKEY_CURRENT_USER\SOFTWARE\Policies\OpenPub (one user); OpenPub then makes no update requests and does not ask. See the FAQ.

Versions before 1.3.0 make no network requests at all. The Microsoft Store version makes no update checks of its own; the Store keeps it up to date.

Other things to know

  • Links: opening a web or email link from OpenPub hands it to your browser or mail program. OpenPub itself does not connect.
  • Spelling: the spelling checker uses a dictionary inside OpenPub. The red underlines while typing use Windows' own spelling service, and Windows may download its English (Australia) language data if it is not installed.
  • Ghostscript: if you install Ghostscript for CMYK PDF export, OpenPub runs it on your computer. Ghostscript makes no network requests for this.
  • Plug-ins: a plug-in you install runs inside OpenPub, and OpenPub warns you before installing one. Only install plug-ins from people you trust.
  • Settings: your settings, personal dictionary and plug-ins are stored in your Windows user profile (%APPDATA%\OpenPub). Uninstalling asks whether to keep them.

This website

This website has no cookies, tracking, analytics or third-party scripts. It is hosted on GitHub Pages, which, like any web host, receives your IP address when you visit; see the GitHub privacy statement linked above.
